# 会话交接

> 将当前对话压缩为交接文档，使另一个 Agent 或下次会话能无缝继续工作。

---

## 触发条件

- 当前会话即将结束，但工作未完成
- 需要将上下文传递给另一个 Agent 继续
- 多 Agent 并行协作时的上下文传递
- 长时间任务需要在多个会话间切换

---

## 交接流程

### 1. 收集当前状态

从当前会话中提取：

```
- 当前正在做什么（任务描述）
- 已经完成了什么（已完成清单）
- 下一步要做什么（待办清单）
- 关键决策和理由（为什么这样选）
- 已知风险/阻塞（需要注意什么）
- 当前打开的文件和上下文
```

### 2. 生成交接文档

存入 `docs/discussions/` 目录：

```markdown
# 交接：[任务简述] - YYYY-MM-DD HH:MM

## 当前任务
[一句话描述正在做什么]

## 已完成
- [x] 事项1
- [x] 事项2

## 待办
- [ ] 事项3（优先级 P0）
- [ ] 事项4（优先级 P1）

## 关键决策
| 决策 | 理由 | 替代方案 |
|------|------|---------|
| 决策1 | 理由1 | 被否决的方案 |

## 当前上下文
- 活跃文件：`src/path/to/file.ts`
- 依赖模块：`module-a`, `module-b`
- 参考文档：`docs/design/app-overview.md`

## 风险/阻塞
- 🔴 阻塞：描述及需要什么来解除
- 🟡 风险：描述及缓解措施

## 验证命令
```bash
pnpm test -- --related
```

## 交接给
[下一个 Agent 应该从哪开始]
```

### 3. 压缩要点

交接文档应精简，只保留恢复工作所需的最小上下文：

- 不要复制代码片段（引用文件路径即可）
- 不要重复已有的文档内容（引用文档路径即可）
- 不要记录过程细节（只记录结论和决策）

---

## 交接信号

文档末尾标注交接状态：

| 状态 | 标记 | 含义 |
|------|------|------|
| 🔴 紧急 | `[URGENT]` | 有阻塞问题，需立即处理 |
| 🟡 进行中 | `[IN_PROGRESS]` | 工作可继续，没有阻塞 |
| 🟢 待验证 | `[AWAITING_REVIEW]` | 工作已完成，等待审查 |
| ⚫ 已完成 | `[DONE]` | 已全部完成，仅作记录 |

---

## 示例

```markdown
# 交接：用户认证模块 — 密码重置功能 — 2026-08-02 15:30

## 当前任务
实现密码重置流程：发送重置邮件 → 验证 Token → 更新密码

## 已完成
- [x] 重置 Token 生成和验证逻辑
- [x] 邮件发送服务集成
- [x] 密码更新接口

## 待办
- [ ] 编写重置流程端到端测试（P0）
- [ ] 添加速率限制（P1）

## 关键决策
| 决策 | 理由 |
|------|------|
| Token 有效期 15 分钟 | 平衡安全性和用户体验 |

## 验证命令
```bash
cargo test -- auth::password_reset
```

[IN_PROGRESS]
```
