# AGE 项目初始化

> 从 AGE 模板初始化一个新项目。当用户克隆模板后说"初始化项目"、"帮我初始化"、"setup project"时触发。

---

## 触发条件

- 用户说"初始化项目"、"初始化"、"帮我初始化这个模板"
- 当前项目根目录存在 `AGENTS.md` 且包含 `{{PROJECT_NAME}}` 占位符
- 用户明确要求从 AGE 模板开始新项目

---

## 初始化流程

### 第 1 步：收集项目信息

向用户询问以下信息（若用户已提供则跳过）：

1. **项目名称**（英文，如 `my-app`）— 必填
2. **仓库地址**（如 `git@github.com:user/my-app.git`）— 选填
3. **一句话描述** — 选填，默认"一个 AGE 驱动的应用项目"

```
示例对话：
AI: 请提供以下信息来初始化项目：
    1. 项目名称（英文，如 my-app）：
    2. 仓库地址（可选）：
    3. 一句话描述（可选）：
```

### 第 2 步：确认配置

展示将要使用的配置，让用户确认：

```
AI: 确认以下配置：
    - 项目名称：my-app
    - 仓库地址：git@github.com:user/my-app.git
    - 项目描述：一个 AGE 驱动的应用项目
    确认开始初始化？(y/n)
```

### 第 3 步：执行替换

扫描所有 `.md` 文件，执行以下替换：

| 占位符 | 替换为 |
|--------|--------|
| `{{PROJECT_NAME}}` | 用户提供的项目名称 |
| `{{REPO_URL}}` | 用户提供的仓库地址 |
| `{{project}}` | 用户提供的项目名称 |
| 其他所有 `{{...}}` | `<!-- TODO: 原占位符内容 -->` |

**具体操作**：

1. 使用 `rg` 或 `grep` 搜索所有包含 `{{` 的 `.md` 文件
2. 对每个文件，用 Edit 工具替换占位符
3. 处理完成后汇报替换数量

### 第 4 步：清理模板文件

删除以下文件（它们仅用于模板初始化，不属于项目本身）：

- `init.ps1`
- `init.sh`
- `init.config.json`

### 第 5 步：可选 Git 初始化

询问用户是否初始化 Git 仓库：

```
AI: 是否初始化 Git 仓库？(y/n)
```

如果用户确认：
1. 删除 `.git` 目录（如果存在）
2. 运行 `git init`
3. 运行 `git add -A`
4. 运行 `git commit -m "从 AGE 模板初始化：<项目名称>"`
5. 如果提供了仓库地址，询问是否添加远程仓库

### 第 6 步：完成提示

```
AI: 初始化完成！下一步：
    1. 搜索 <!-- TODO 补充剩余内容
    2. 填写 docs/backlog/ 第一个工作项
    3. 填写真实可执行的验证命令
    4. 开始编码！
```

---

## 替换规则细节

### 精确匹配替换

以下占位符用用户提供的值精确替换：

- `{{PROJECT_NAME}}` → 项目名称
- `{{REPO_URL}}` → 仓库地址
- `{{project}}` → 项目名称

### TODO 标记替换

所有其他 `{{任意内容}}` 替换为 `<!-- TODO: 任意内容 -->`，保留原始占位符内容作为提示。

### 文件范围

- **包含**：所有 `.md` 文件
- **排除**：`.git` 目录下的文件

---

## 注意事项

- 替换前先展示变更清单，获得用户确认
- 使用 UTF-8 编码写回文件
- 批量处理同一文件的多个占位符，减少 Edit 调用次数
- 如果用户只提供了部分信息，使用默认值填充
- 初始化完成后，提醒用户本技能文件（`docs/skills/age-init.md`）可保留作为参考
