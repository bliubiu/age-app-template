## 审查清单

### 规范审查

- [ ] 代码风格符合项目规范（命名、缩进、格式）
- [ ] 无硬编码的敏感信息（密钥、密码、Token）
- [ ] 日志级别使用正确
- [ ] 错误处理完整（所有异常路径有处理）
- [ ] 无安全漏洞（注入、XSS、CSRF）
- [ ] 依赖方向正确（高层不依赖低层细节）

### 需求审查

- [ ] 所有需求点已覆盖
- [ ] 验收标准全部满足
- [ ] 边界情况已处理
- [ ] 非功能需求（性能、安全、兼容性）已满足
- [ ] 无功能遗漏

### 测试审查

- [ ] 单元测试覆盖核心逻辑
- [ ] 集成测试覆盖关键流程
- [ ] 测试可独立运行
- [ ] 测试断言有意义（非空断言）
- [ ] 回归测试已通过

### 文档审查

- [ ] 公开 API 有文档
- [ ] 配置项有说明
- [ ] 架构图与实现一致
- [ ] CHANGELOG 已更新

## 最终结论

- [ ] ✅ **通过** — 无阻塞问题，可以合并
- [ ] ⚠️ **有条件通过** — 建议改进已记录，不阻塞合并
- [ ] ❌ **不通过** — 存在阻塞问题，必须修复后重新审查
