# 代码约定

> 本文件包含所有参与此项目需遵守的通用代码风格和命名规范。

---

## 缩进和格式

- **缩进**：必须使用空格符，不能使用 Tab 缩进。按语言区分：
  - **2 个空格**：TypeScript / JavaScript / JSON / YAML / HTML / CSS / SCSS / Vue / JSX / TSX
  - **4 个空格**：Go / Python / Rust / Java
- **编码**：UTF-8
- **换行符**：LF（参见 `.editorconfig`）
- **注释**：统一使用中文注释说明，采用 Doxygen 风格；标点使用半角符号，标点后需跟一个空格；单行注释行尾不加句号、逗号、分号、冒号等收尾标点
- **时间格式**：`yyyy-MM-dd HH:mm:ss.SSS`
- **模块化/插件式**：解耦
- 优先选用 yaml 格式配置文件

---

## 行长度与换行

- 每行不超过 120 个字符，超长应换行
- 函数参数过多时应换行对齐
- 函数单一职责，超过 50 行考虑拆分

---

## 注释规范

- 公共函数/方法需包含 JSDoc/GoDoc 风格注释
- 使用 `// TODO:` 和 `// FIXME:` 标记临时代码，并注明负责人或截止日期

---

## 导入排序

1. 标准库
2. 第三方库
3. 本地模块

---

## 命名规范

### Go 语言

- **包名**：全小写，无下划线，简洁（如 `userapi`）
- **结构体**：大驼峰（如 `UserInfo`）
- **接口**：大驼峰，通常以 `er` 结尾（如 `Reader`）
- **函数/方法**：小驼峰（如 `getUserName`）
- **变量**：小驼峰（如 `userCount`）
- **常量**：全大写，下划线分隔（如 `MAX_RETRY`）
- **私有标识符**：以小写字母开头，包内可见

### TypeScript/JavaScript

- **类/接口**：大驼峰（如 `UserService`）
- **函数/方法**：小驼峰（如 `fetchUserData`）
- **变量**：小驼峰（如 `isLoading`）
- **常量**：全大写，下划线分隔（如 `API_TIMEOUT`）
- **组件文件**：大驼峰（如 `UserProfile.tsx`）
- **工具函数文件**：小驼峰（如 `formatDate.ts`）

### Python

- 默认使用 `UV` Python 包管理工具，除非明确指定
- 默认使用 4 个空格进行缩进，禁止使用 Tab
- 默认遵循 PEP 8 代码风格
  - 变量名：小写字母，单词之间使用下划线分隔
  - 函数名：小驼峰式命名法（lowerCamelCase）
  - 类名：大驼峰式命名法（UpperCamelCase）
  - 模块名：小驼峰式命名法（lowerCamelCase）
- 文档字符串（docstrings）用于描述模块、类或函数的用途
- 默认优先使用列表推导式

### Rust

- **模块/包**：蛇形命名（如 `user_service`）
- **结构体/枚举/Trait**：大驼峰（如 `UserService`）
- **函数/方法**：蛇形命名（如 `get_user_name`）
- **变量**：蛇形命名（如 `user_count`）
- **常量/静态变量**：全大写，下划线分隔（如 `MAX_RETRY`）
- **宏**：蛇形命名或小驼峰

---

## 接口规范

- 统一返回结构：`{ code, message, data }`
- 错误码必须有对应文档，不能随意自定义
- 分页接口必须支持 `page` + `pageSize`，最大 pageSize 100
- 写操作必须做幂等

---

## 语言要求

- AI 的所有思考过程、计划、执行过程及总结内容交互信息必须使用中文输出
- 生成代码必须使用英文，注释必须使用中文
- 生成的实施计划、任务、操作指南文档必须使用中文输出
- 统一使用 UTF-8 编码
